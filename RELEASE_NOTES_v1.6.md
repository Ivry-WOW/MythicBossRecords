## Mythic Boss Records V.1.6

- Only keys **+9 and higher** are counted.
- Tooltips and tops follow the current **Tyrannical / Fortified** week.
- Each player's **combat log is imported automatically** (MBR Tools, every 15 min) and shared with everyone.
- New **Update** and **Sync logs** buttons.
- Class list per boss is sorted best to worst.
- Fixed: the Users list showing old versions.

**Install:** extract to `Interface\AddOns\`, run `MBR Tools.cmd` → 1 (once).
